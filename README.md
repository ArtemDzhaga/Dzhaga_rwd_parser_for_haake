# Парсер HAAKE RheoWin

Локальный инструмент для переноса измерений из бинарных файлов RheoWin `.rwd`
в Excel и построения графиков через `matplotlib` и диаграммы Excel.

В режиме `auto` проект работает в два шага:

1. `haake_cli.py` читает `.rwd`, заполняет `input_data` и формирует
   `output_data` с первыми 20 точками каждой серии.
2. `haake_plot.py` строит графики из `output_data`.

ASCII-файл RheoWin нужен для описания колонок и сегментов. Числовые значения
по умолчанию всегда берутся из `.rwd`. Один ASCII можно использовать для
нескольких `.rwd`, если в них одинаковая структура измерений.

## Быстрый запуск

Самый удобный режим — интерактивный. Файлы и папки можно перетаскивать в
терминал мышью.

```bash
cd /Users/artem/Desktop/Output/iam_ras/haake_parser
python3 haake_cli.py
```

Сначала выберите режим: `auto` или `custom`. Enter выбирает `auto`.
Все вопросы с настройками показывают значение по умолчанию в квадратных
скобках. Обязательные пути, для которых нет подходящего значения по умолчанию,
потребуется указать. Ctrl+C завершает запуск.

В `auto` порядок вопросов вопросов следуюший:

1. Excel-шаблон `.xlsx`.
2. ASCII-файл RheoWin `.txt`, `.asc` или `.csv`.
3. Один или несколько `.rwd` либо папку с `.rwd`.
4. Нужно ли искать `.rwd` во вложенных папках.
5. Считать ли папки отдельными сериями.
6. Лист Excel для записи, обычно `input_data`.
7. Путь к новой итоговой книге.
8. Использовать ли ASCII также как источник числовых данных.
9. Нужен ли технический лист `raw_values`.

После создания книги постройте графики:

```bash
python3 haake_plot.py
```

По умолчанию скрипт предлагает использовать лист `output_data`.

## Пошаговый режим custom

Для парсинга и графиков используются **отдельные запуски**:

```bash
cd /Users/artem/Desktop/Output/iam_ras/haake_parser
python3 haake_cli.py custom
```

После создания книги:

```bash
python3 haake_plot.py custom
```

В обоих случаях сначала выбирается подход и шаблон `B_draft` или
`K_draft`, затем язык `en` или `ru`, затем программа задает вопросы по шагам.
Язык определяет вопросы мастера и новые подписи графиков. В B_draft он
также определяет названия листов и заголовки расчетной таблицы. Заголовки
исходных каналов и существующего шаблона K_draft сохраняются. Технические
сообщения старого ядра K_draft пока остаются на русском.

| Подход | Что обрабатывается | Шаблон и расчет |
| --- | --- | --- |
| B_draft | Вязкость при разных концентрациях, номинальных температурах, валах и условиях магнитного поля | Встроенный шаблон новой книги; среднее Eta по точкам №50 и №100 каждого сегмента |
| K_draft | Частотные осцилляционные серии при разных напряжениях | Выбранная книга с `input_data`; `output_data` собирается из первых 20 точек |

Можно заранее выбрать сценарий и язык короткой командой, а остальные
параметры ввести в диалоге:

```bash
python3 haake_cli.py custom --profile B_draft --language ru
python3 haake_plot.py custom --profile K_draft --language en
```

Запись `--mode custom` равнозначна `custom`. В `auto` используется прежний
русскоязычный диалог; `--profile` и `--language` относятся к `custom`.
При запуске со старыми позиционными аргументами диалог не появляется.

### B_draft

1. Укажите папку или несколько RWD-файлов. Поиск во вложенных папках включен
   по умолчанию.
2. Имена файлов определяют вещество, объемную долю, вал и поле:
   `Fe3O4_1`, `TiO2_5`, `custom`/`Alum`, `standart`/`standard`,
   `control`, `magnit`/`magnet`. `custom` в имени файла означает вал **Alum**
   и не связан с режимом запуска `custom`. Второй вал обозначается **Standart**.
   Если имя неоднозначно, мастер предлагает пропустить файл (`skip`) или
   указать условия явно (`specify`). Имя пропущенного файла выводится в терминале.
3. ASCII ищется рядом с RWD, либо можно указать эталоны отдельно.
   Нужен эталон подходящей структуры для каждого отличающегося скрипта.
4. Номинальные температуры сегментов по умолчанию: `20 30 40 50 60` °C.
   Измеренная температура не используется для фильтрации или замены номинальной.
5. Точки для расчета по умолчанию: `50` и `100`.
   **Eta = (Eta₅₀ + Eta₁₀₀) / 2** — как `(D51+D101)/2` в `46nm_3&4.xlsx`.
   Промежуточные точки не усредняются. Если нужной точки нет или ее Eta
   непригодна, импорт останавливается с указанием файла и сегмента.
6. Выберите имя новой книги. Существующая книга не перезаписывается.

Русский шаблон содержит `Сырые данные`, `Расчеты`, `Итоги`, `Легенда`;
английский — `Raw data`, `Calculations`, `Results`, `Legend`.
Легенда остается пустой. В сырых данных сохраняются значения RWD без
округления; показанные в расчетах пять знаков — формат отображения.
Строки двух исходных точек находятся в скрытых столбцах J–K расчетного листа.
Размер частиц из этих данных не выводится и не анализируется.

Магнитное изменение: `Eta(магнит)/Eta(контроль) − 1`, в процентах.
Отношение валов: `Eta(Alum)/Eta(Standart)`. Сопоставляются одинаковые
вещество, концентрация, номинальная температура и остальные условия.
При отсутствии пары ячейка остается пустой, а не нулевой.
Две записи одной и той же группы считаются дубликатом и требуют уточнения.

Отдельный мастер графиков читает книгу, созданную этим сценарием.
По умолчанию формат `xlsx`: в новой копии книги заполняется лист итогов
редактируемыми диаграммами «линия + точки». Числа для этих диаграмм записаны
на том же листе в столбцах AD–AE; это снимок расчета на момент запуска.
При изменении исходных измерений повторно запустите построение по исходной
книге парсера. Входная книга сохраняется.
Также доступны `png`, `svg`, `pdf`, несколько форматов через пробел.
Excel не требуется открывать перед построением: генератор вычисляет
двухточечное среднее по ссылкам на исходные ячейки.

Набор графиков включает:

- Eta от концентрации, отдельно по веществу, валу и полю;
- Eta от номинальной температуры **для каждой имеющейся концентрации**;
- магнитное изменение от концентрации для доступных пар.

### K_draft

Мастер предлагает шаблон `input/may_proj_template_first20_clean.xlsx`;
его можно заменить своим. Затем указываются ASCII, RWD/папка, вложенность,
группировка папок, лист, новая итоговая книга и дополнительные опции.
Числовой импорт выполняет существующее ядро, включая проверки дубликатов
и пересборку `output_data`.

В отдельном мастере графиков выбираются книга, папка результата, лист,
число точек (20), полиномиальная линия (включена, степень 3), форматы (PNG),
метрики, частоты, разделение по смесям (включено), серии, столбцы легенды (1)
и DPI (300). Все значения можно изменить до запуска обработки.
При отключении полинома его степень не запрашивается.

## Запуск с аргументами

Порядок позиционных аргументов у импортера всегда один:

```text
haake_cli.py Excel-шаблон ASCII-структура .rwd-или-папка [другие-.rwd-или-папки]
```

Обязательный флаг для импорта по старой полной команде:

```text
--sheet input_data
```

Путь результата можно задать через `-o итоговая_книга.xlsx`; без `-o`
создается книга рядом с шаблоном с суффиксом `_parsed_дата_время`.

Для поиска во вложенных папках добавьте `--recursive`.

Полный список параметров:

```bash
python3 haake_cli.py --help
python3 haake_plot.py --help
```

## Правила обработки

### Идентификация эксперимента

Состав, напряжение и заявленный диапазон частот определяются по имени
переданного `.rwd`. Внутренние пути RheoWin могут сохранять старое имя после
переименования файла; при расхождении программа выводит предупреждение, но не
подменяет значение из имени файла.

### Частоты

Данные приводятся к общей сетке отчёта:

```text
0.1, 0.5, 1, 5, 10, 20, 30, 50, 75, 100 Гц
```

Близкие измеренные значения автоматически относятся к соответствующему
стандартному блоку. Например, `30.66` Гц записывается как `30` Гц, а `51.1`
Гц — как `50` Гц.

### Дубликаты и неполные сегменты

Перед сохранением парсер проверяет `input_data` на одинаковые числовые блоки.
Если один набор точек оказался в разных частотах или секциях, импорт
останавливается. Флаг `--allow-duplicates` предназначен только для отладки.

В текущем ядре K_draft сегмент без физически валидных строк не записывается.
Если валидна только часть строк, сегмент сохраняется с предупреждением.
Сообщение в консоли указывает имя файла, частоту и число пригодных строк.
Это не подтверждает пригодность неполного сегмента для научного анализа.

### ASCII как источник значений

Обычный ASCII-файл описывает структуру и не переносится в итоговую книгу.
Чтобы намеренно взять измерения из ASCII, используйте
`--include-ascii-data` или передайте отдельный файл через `--data-ascii`.

## Листы Excel

- `input_data` — исходные извлечённые значения, до 30 точек в подблоке.
- `output_data` — первые 20 точек для построения графиков.
- `instrument_metadata` — метаданные измерительного прибора и файла.
- `freq_diagrams` — место в шаблоне для итоговых изображений; парсер не
  вставляет туда графики автоматически.
- `raw_values` — технический лист, добавляется только с
  `--include-diagnostics`.
- `parser_mapping` — скрытая техническая карта соответствия каналов.

Этот список относится к `auto` и `custom → K_draft`.

## Графики

`haake_plot.py` строит логарифмические диаграммы для `G'`, `G''`, `|eta*|` и
`tan delta` относительно `gamma`.

Полезные параметры:

```text
--points 20              первые точки каждого подблока
--poly-order 3           степень сглаживающего полинома
--no-fit                 только точки, без сглаживания
--legend-columns 1       число столбцов легенды
--split-by-series        отдельные графики для каждой серии
--series                 отобрать конкретные серии
--formats png svg pdf    форматы сохранения
--frequencies            отобрать частоты
```

Полином строится в логарифмических координатах и служит только визуальной
направляющей. Если аппроксимация становится неустойчивой, программа понижает
её порядок; если устойчивую кривую получить нельзя, показывает только точки.
Для количественного анализа используйте исходные точки, а не линию сглаживания.

## Выгрузка CSV без Excel-шаблона

Если эксперимент не подходит к существующему шаблону, можно извлечь таблицы в
CSV без построения Excel-книги:

```text
haake_cli.py csv папка-или-файлы --recursive -o папка_для_csv
```

В папке результата создаются файлы измерений, `_summary.csv`, `_metadata.csv`
и `_mapping.csv`. Флаг `--decimal-comma` записывает числа с десятичной запятой,
а `--raw-values` отключает округление до разрядности RheoWin.

```text

├── haake_cli.py                 точка входа импортера Excel и CSV

├── haake_rheo/
│   ├── excel_import.py          ASCII, RWD, Excel, CSV и валидация
│   ├── plot.py                  чтение output_data и matplotlib-графики
│   ├── wizard.py                выбор режимов и пошаговые вопросы
│   └── B_draft.py               вязкость, номинальная T, концентрация и магнит
├── docs/
│   └── parser_usage_sequence.puml
├── input/                       шаблоны и локальные исходные данные
├── output/                      локальные результаты, не добавляются в Git
├── outputs/                     новые результаты custom, не добавляются в Git
├── tests/
│   ├── test_excel_import.py
│   └── test_plot.py
├── requirements.txt
└── README.md
```

ASCII можно получить в RheoWin Data Manager экспортом готового `.rwd` или
добавить соответствующий блок в рабочий скрипт Job Manager.
